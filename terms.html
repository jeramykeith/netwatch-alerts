Program name and description

HomeLab NetWatch Alerts is the text-message (SMS) program of NetWatch, the home-network monitoring and parental-control software operated by HomeLab (sole proprietor). The software sends automated alerts about the home network to the account owner who opted in:

  • A managed profile asks for more internet time. The account owner can reply YES (15 more minutes), YES followed by a number of minutes, or NO, and gets one text confirming the answer.
  • A managed profile reaches its daily time limit.
  • A website is blocked by a rule or filter, a watched website is visited, or an app is used for the first time.
  • An optional evening summary of time online for each managed profile.

Who receives messages

The NetWatch account owner, who opts in by entering their mobile number in the NetWatch dashboard and turning on Alerts by text. One confirmation text is sent when the number is saved. See How Opt-In Works.

Message frequency

Message frequency varies with activity on the home network.
