NetWatch Alerts – Terms and Conditions

Effective November 5, 2026 · Program operated by HomeLab, a household (sole proprietor)

Program name and description

NetWatch Alerts sends text messages about one household's home network to that household's account owner. Messages include a child asking for more internet time, a daily time limit being reached, and a blocked website. The owner can reply YES (15 more minutes), YES followed by a number of minutes, or NO to answer a request for more time.

Who receives messages

Only the household's account owner, who opts in by entering their own mobile number on the private NetWatch settings page and turning alerts on. A confirmation text is sent when alerts are turned on. The program is not offered to the public.

Message frequency

Message frequency varies, usually a few messages a day.

Cost

Message and data rates may apply.

Help

Opting out

Reply STOP to any message to cancel. You will receive one confirmation and no further messages. Reply START to sign up again.
