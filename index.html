HomeLab NetWatch Alerts

Automated text-message alerts from NetWatch, the home-network monitoring and parental-control software operated by HomeLab (sole proprietor).

What the program does

NetWatch runs on a small server on the home network it monitors. HomeLab NetWatch Alerts is its text-message program: the software sends an alert to the account owner's mobile number when something on that network needs attention. Every message is generated and sent by the software in response to a network event.

  • A managed profile asks for more internet time. The account owner can reply YES (15 more minutes), YES followed by a number of minutes, or NO, and gets one text confirming the answer.
  • A managed profile reaches its daily time limit.
  • A website is blocked by a rule or filter, a watched website is visited, or an app is used for the first time.
  • An optional evening summary of time online for each managed profile.

Help and support

  • Stop the texts: reply STOP to any message, or turn off Alerts by text in the NetWatch dashboard under Family > Alerts > On your phone.
  • Start them again: text START to +1 (424) 433-6193.
  • Change the number or the kinds of alerts: use the same dashboard screen.
  • Anything else: text HELP to +1 (424) 433-6193.
